# Personal Portfolio Website

My personal portfolio website built from scratch using HTML and CSS, hosted on GitHub Pages.

🔗 [remasalroubie.github.io/RemasAlroubie](https://remasalroubie.github.io/RemasAlroubie)

---

## About

I built this site to showcase my projects, skills, and certificates as a Data Science student. It started simple and I kept improving it — adding animations, a language toggle, and interactive sections over time.

---

## Features

- Fully bilingual — Arabic and English with one click
- Responsive design for all screen sizes
- Animated hero section with typing effect
- Interactive skills page with flip cards
- Projects timeline with filter and modal
- Certificates page with counter animation
- Contact form connected to Formspree

---

## Built With

HTML · CSS · JavaScript · GitHub Pages

---

## Pages

- **Home** — Introduction and quick stats
- **Work** — Projects timeline with filter
- **Skills** — Flip cards for each skill
- **Certificates** — All 10 certificates
- **Contact** — Form + social links
